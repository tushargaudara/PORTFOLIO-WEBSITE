# 🌐 Personal Portfolio Website

A clean, modern, and fully responsive **portfolio website** built using **HTML & CSS**.  
This project is **Day 1** of my **15 Frontend Projects in 15 Days Challenge**.

---

## 🚀 Features

- 🌑 Dark, modern UI  
- 📌 Sticky navigation bar  
- 🎨 Gradient buttons  
- ✨ Smooth fade-in animations  
- ⚡ Fast & lightweight  
- 📱 Fully responsive for all screens  
- 🔥 Clean hero section  
- 🧩 Projects section  
- 📞 Contact section
